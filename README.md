# Aswath S — UI/UX Designer Portfolio

A modern, dark luxury, interactive portfolio website for **Aswath S (UI/UX Designer)** inspired by high-end design systems and interaction patterns.

## 🚀 Live Preview
Open `index.html` in any modern web browser or run:
```bash
npx serve .
```

## 🛠️ Features
- **Dark Luxury Aesthetic**: Deep obsidian palette, glassmorphism cards, hairline borders, and electric blue accents.
- **Modern Typography**: Space Grotesk (architectural headings) & Plus Jakarta Sans (body).
- **Interactive Bento Grid**: Filterable skills, methodology, and software tools.
- **Deep-Dive Case Studies**:
  - *Seaways Mobile App* — Cruise trip booking & rental prototype.
  - *Seaways Landing Page* — Conversion-focused web platform.
  - *Grocery Retail Mobile App* (Pirai Infotech).
  - *Medsocio Healthcare App* (EdXL Learning).
- **Built-in Resume Modal**: Formatted printable/exportable CV view.
- **Floating Navigation Dock**: Quick-jump navigation and active section tracking.
- **Live IST Clock**: Real-time Indian Standard Time ticker.
